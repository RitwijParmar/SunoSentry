# Live demo v2

The revised recording uses the deployed Cloud Run application at
`https://sunosentry-benchmark-mgj5wuno7q-uc.a.run.app/` and a slower,
conversational English-India narration.

The interaction is timed to the narration:

1. A realistic water-leak request is entered and sent.
2. The application produces a dispatch proposal without booking anything.
3. The confirmation turn is explicit and moves the request to human review.
4. The page scrolls to the trace so triage, grounding, planning, consent, and the
   signed evidence are visible.

The video adds pen-style callouts for the conversation, observability and safety
panel, consent gate, human handoff, trace evidence, and the simulated-system
boundary. The voice is a local `Aman` English-India system voice; it is not a
voice clone and no live technician, calendar, payment, or telephony action is
performed.
